Управление

Короткая памятка по редактору

Левая кнопка мыши
Выбрать ноду и открыть редактор. Потяни выход одной ноды к входу другой, чтобы соединить их.
Правая кнопка мыши
Перемещает ноду. На пустом поле — двигает весь холст.
Колесо мыши
Приближает и отдаляет граф относительно курсора. Ctrl не нужен.
Нажатие на колёсико
Создаёт ноду в точке курсора.
Backspace / Delete
Удаляет выбранную ноду, если фокус не находится в поле ввода.
N / V / F
Добавить ноду / переменную / уместить граф в рабочее поле.
Изменения сохраняются автоматически.
